## 🚀 How to Host on GitHub & Deploy 100% FREE

### Step 1: Create a Repository on GitHub
1. Open [github.com](https://github.com) and click **"New repository"**.
2. Repository name: `black-xera`
3. Set to **Public** and click **"Create repository"**.

### Step 2: Push this Code to GitHub
Open your terminal in this project and run:
```bash
git init
git add .
git commit -m "Initial commit for BLACK XERA store"
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/black-xera.git
git push -u origin main
```

### Step 3: Deploy to Vercel (Free 24/7 Hosting)
1. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New..."** -> **"Project"**.
3. Select your `black-xera` repository.
4. Framework Preset: **Vite**
5. Click **"Deploy"**!
6. Your live website will be ready in 30 seconds at `https://black-xera.vercel.app`!
